Rectangle Wall-Thickness Generator

In progress
Grasshopper / parametricBoundary operationsPlan generation

Overview

A parametric rectangle definition with a slider-driven offset. The offset boundary is subtracted from the original rectangle, outputting the difference — effectively a range of wall thickness options controlled by one parameter. Intended as the base geometry logic for plan-generation experiments.

How it works

  • Input: base rectangle (x/y dimensions)
  • Control: single slider sets the offset distance
  • Operation: boundary difference (outer − inner)
  • Output: closed wall polygon with parametric thickness
